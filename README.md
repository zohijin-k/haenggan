# 행간 (haenggan) — space between lines

친구들과 전자책 한 권을 같이 읽으면서, 각자 읽은 만큼만 서로의 밑줄과 메모가 드러나는
개인용 MVP. Next.js(App Router) + Supabase + epub.js.

## 1. Supabase 프로젝트 준비

1. https://supabase.com 에서 새 프로젝트 생성
2. 왼쪽 메뉴 SQL Editor 에서 `supabase/schema.sql` 내용을 그대로 실행
3. 왼쪽 메뉴 Storage 에서 `books` 라는 이름의 버킷 생성
   - 개인용 MVP라 우선 **Public** 버킷으로 만들면 제일 간단함
   - Project Settings → API 에서 `Project URL` 과 `anon public` 키를 복사

## 2. 환경변수 설정

```bash
cp .env.local.example .env.local
```

`.env.local` 을 열어 위에서 복사한 값을 채워넣기.

## 3. 설치 & 실행

```bash
npm install
npm run dev
```

http://localhost:3000 접속.

## 4. 첫 테스트

- "새로 시작하기"에서 `public/sample-books/sample.epub` (스캐폴딩용 짧은 샘플, 4챕터)을
  업로드해서 흐름부터 확인해보기
- 실제로 같이 읽고 싶은 책은, 본인이 정식으로 구매/소장한 **DRM 없는** EPUB 파일로 준비해서
  같은 방식으로 업로드하면 됨. 상업 전자책 대부분은 DRM이 걸려있어 이 방식으로는 못 씀 —
  DRM 없는 배포본(작가 직판, 퍼블릭 도메인, 셀프퍼블리싱 등)이 현실적인 선택지.
- 세션을 만들면 6자리 초대 코드가 생김. 친구에게 코드를 알려주고,
  랜딩 페이지의 "초대받았어요" 쪽에서 코드+닉네임으로 들어오면 끝.

## 핵심 동작 원리

- **발견 메커니즘**: 각자의 `reading_progress.furthest_cfi`(가장 멀리 읽은 위치)를 기준으로,
  그 지점 이전에 남겨진 친구의 밑줄만 화면에 나타남. 내가 아직 안 읽은 구간의 메모는
  아예 렌더링하지 않기 때문에 스포일러가 안 됨 — 실물 책 페이지를 넘기다 낙서를 우연히
  마주치는 느낌을 재현하려는 의도.
- **색 = 손글씨 정체성**: 참여자마다 고정된 색 하나를 배정받음(팔레트는 `lib/palette.ts`).
  형광펜 색을 매번 고르게 하지 않고, "이 색은 항상 이 사람"이라는 인식을 만들려는 선택.
- **계정 없는 인증**: 정식 로그인 대신, 세션 코드 + 닉네임으로 `localStorage`에 신원을
  저장하는 아주 가벼운 방식(`lib/identity.ts`). 친구 몇 명과 쓰는 개인 프로젝트엔 충분하지만,
  나중에 진짜 서비스로 확장할 때는 Supabase Auth 등 제대로 된 인증으로 바꿔야 함.

## 알려진 한계 (다음에 손볼 것들)

- RLS를 전부 열어둔 상태(`schema.sql` 하단 정책 참고) — 코드/세션 id를 아는 사람만
  쓴다는 전제의 개인용 설정. 외부에 공개할 거라면 반드시 강화 필요.
- `book.locations.generate()`가 큰 책에서는 시간이 좀 걸릴 수 있음 — 로딩 중엔 진행률
  퍼센트가 0으로 보일 수 있음.
- 하이라이트 "발견 애니메이션"은 기본적인 트랜지션만 적용되어 있음. 잉크 번지는 느낌 등
  더 감성적인 마이크로 인터랙션은 추후 다듬을 부분.
- EPUB 표지/메타데이터 추출은 파일에 따라 실패할 수 있음(그럴 땐 파일명으로 대체됨).

## 나중에 실서비스로 확장한다면

- 콘텐츠 소싱: 사용자 업로드(DRM 없는 파일) 또는 저작권 열린 콘텐츠(웹소설/브런치류)로
  시작하는 게 현실적. 상업 전자책 플랫폼 연동은 DRM 때문에 별도 제휴 없이는 어려움.
- 인증: Supabase Auth(이메일 매직링크 등)로 교체, RLS를 `auth.uid()` 기반으로 재작성.
- 리텐션: 한 권이 끝나면 세션이 종료되는 구조라, 다음 책 추천/이어읽기 흐름을 추가하면 좋음.
